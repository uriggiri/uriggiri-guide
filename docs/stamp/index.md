# 스탬프 이벤트

무인키즈카페 예약을 **이용한 시간만큼 스탬프로 쌓아**, 일정 개수를 채우면 이용권을 주는
고객 리텐션 프로그램입니다. 고객은 별도 앱 없이 링크로 들어와 자기 현황을 보고,
본사는 대시보드에서 이벤트를 관리하며, 매장은 고객이 가져온 이용권을 사용 처리합니다.

## 한 문장으로

> 1시간 이용 = 스탬프 1개, 스탬프 10개 = 3만원 이용권. 채울 때마다 반복 발급.

## 세 개의 화면

| | 쓰는 사람 | 하는 일 |
|---|---|---|
| **고객 화면** | 예약 고객 | 본인인증 후 내 스탬프·이용권 확인, 참여매장 확인 |
| **관리자 화면** | 본사 | 이벤트 설정, 참여매장 지정, 지급·정산·발송 이력 확인 |
| **매장 앱** | 지점 | 고객이 제시한 이용권을 사용 처리 |

## 스탬프가 쌓이는 순서

```
① 고객이 네이버 예약으로 매장 이용
        ↓  (이용 완료)
② 다음날 15:10 — 전일자 예약 데이터 수집
        ↓
③ 15:20 — 이용시간 합산 → 스탬프 환산 → 조건 충족 시 이용권 발급
        ↓
④ 15:30 / 15:40 — 최초 적립 · 이용권 지급 알림톡 발송
```

**이용 완료 다음날 오후 3시 이후**에 스탬프가 반영됩니다. 이용 당일에는 보이지 않습니다.
고객 안내에서 가장 자주 나오는 질문이라 알림톡 본문에도 같은 문구를 넣어 두었습니다.

## 스탬프 환산 규칙

- **하루 단위로 합산한 뒤** 1시간마다 1개, 남는 시간은 버립니다
- 같은 날 두 번 예약했다면 합쳐서 계산합니다 (1시간 + 1시간 30분 = 2시간 30분 → **2개**)
- 30분씩 따로 예약한 두 건도 합치면 1시간이라 **1개**가 됩니다
- 참여매장에서 이용한 예약만 인정합니다

::: warning 스탬프 개수는 어디에도 저장하지 않습니다
예약 데이터에서 **매번 다시 계산**합니다. 그래서 지난 예약이 뒤늦게 수집·수정돼도
스탬프가 저절로 맞춰지고, 같은 계산을 몇 번 돌려도 중복 발급이 생기지 않습니다.
:::

# 고객 화면

`event.uriggiri.site` — 알림톡 하단 **「이벤트 현황·참여매장 확인」** 버튼으로 들어옵니다.
설치할 앱도, 가입할 계정도 없습니다.

## 들어오는 순서

### 1. 본인인증

이름과 휴대폰 번호를 넣고 **인증요청** → 문자로 오는 6자리 코드를 입력합니다.

- 인증번호는 **5분** 유효, 5회 틀리면 새로 받아야 합니다
- 같은 번호로 **1분 안에** 다시 요청할 수 없고, 하루 20회까지입니다
- 이름·번호만 넣고 엔터를 쳐도 인증요청으로 동작합니다

::: tip 왜 인증을 받나요
스탬프는 예약할 때 쓴 **휴대폰 번호로 묶입니다.** 남의 번호로 조회되면 안 되니
번호 소유를 확인하는 절차입니다.
:::

### 2. 동의

처음 들어온 고객만 거칩니다.

- **개인정보 수집 및 이용** — 필수
- **마케팅 정보 수신** — 선택. 거부해도 이벤트 참여에는 제한이 없지만,
  할인·이벤트 혜택 안내를 못 받습니다

### 3. 스탬프 화면

동의를 마치면 본 화면입니다. 세션은 24시간 유지되므로 그 안에는 다시 인증하지 않습니다.

## 화면에 있는 것

**스탬프 판** — 이번 판의 진행 상황입니다. 10칸이 차면 새 판이 시작되고,
채워진 판은 이용권으로 바뀌어 아래에 쌓입니다.

**내 이용권** — 발급받은 이용권이 **오래된 순**으로 놓입니다. 카드 색으로 상태를 구분합니다.

| 상태 | 표시 |
|---|---|
| 사용 가능 | 기본 · 남은 기간 `D-45` 배지 |
| 만료 임박 (30일 이하) | 주황 — 알림톡도 이때 나갑니다 |
| 사용 완료 | 회색 · 사용 처리한 날짜 표시 |
| 기간 만료 | 회색 · 사용 불가 |

**지급 내역** — 받은 이용권마다 **발급일 · 사용기한 · 남은 일수**가 함께 보입니다.
30일 이하로 남으면 주황색으로, 사용을 마쳤거나 기간이 지나면 회색으로 바뀝니다.

**예약 내역** — 스탬프의 근거가 된 예약입니다. 쿠폰을 쓴 건에는 쿠폰 배지가 붙습니다.

**참여 매장 확인** — 지역별로 묶인 참여매장 목록입니다. 매장이 늘거나 빠지면
목록이 바로 따라갑니다. 미참여 매장도 아래에 따로 보여 줍니다.

## 이용권 쓰는 법

1. 참여매장 중 원하는 지점에 **2시간 이상** 예약
2. **이용 당일, 이용 시간 안에** 해당 지점 네이버 톡톡으로 이용권 적용 요청
3. 지점이 확인 후 3만원 환불 처리
4. 톡톡 회신으로 처리 확인

::: danger 이용 시간이 지나면 처리할 수 없습니다
예약이 자동 확정된 뒤에는 되돌릴 수 없습니다. **반드시 이용 당일에** 요청해야 합니다.
:::

**함께 쓸 수 없는 것**

- 매장 자체 할인·쿠폰·1+1 등과 중복 불가
- 매점 결제 건은 스탬프 적립 대상에서 제외
- 양도·현금 전환 불가
- 이벤트 미참여 매장에서는 사용 불가

## 자주 나오는 문의

**Q. 어제 이용했는데 스탬프가 안 보여요**
이용 완료 **다음날 오후 3시 이후**에 반영됩니다. 그 시각이 지났는데도 없다면
예약할 때 쓴 번호와 인증한 번호가 다른 경우가 대부분입니다.

**Q. 1시간 30분 이용했는데 1개만 찍혔어요**
남는 30분은 버립니다. 다만 **같은 날** 다른 예약이 있으면 합산되므로,
30분 + 30분은 1개가 됩니다.

**Q. 이용권이 사라졌어요**
유효기간(90일)이 지나면 사용할 수 없게 됩니다. 만료 30일 전에 알림톡이 한 번 나갑니다.

**Q. 인증번호가 안 와요**
1분 안에 재요청하면 막힙니다. 잠시 뒤 다시 시도하고, 그래도 안 오면 번호를 확인해 주세요.

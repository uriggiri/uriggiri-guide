# 영업관리 (문의 통합 CRM)

`통합 관리 › 영업관리` — 관리자 · 본사 담당자가 씁니다.

홈페이지(bahnauto.kr)의 **무료체험 신청 · 매장매니저 지원 · 도입 상담 신청**, 반오토 **점주 회원가입**,
전화·카톡으로 받아 **손으로 적은 문의**가 한 목록에 쌓입니다. 한 건마다 처리 상태 · 담당자 · 다음 액션 · 상담 메모를 남깁니다.

## 문의는 어디서 오나

| 접수 경로 | 어떻게 들어오나 | 유형 |
|---|---|---|
| 홈페이지 | bahnauto.kr 의 폼 → [접수 API](../api-leads) | 무료체험신청 · 매니저지원 · 도입상담신청 |
| 회원가입 | 점주(STORE_OWNER)가 반오토에 가입하면 자동 생성 | 무료체험신청 |
| 수동 등록 | 화면 우상단 「수동 등록」 | 넷 중 하나 |

접수번호는 유형별 접두어 + 일련번호입니다: `T-0001`(체험) · `M-0001`(매니저) · `C-0001`(상담) · `X-0001`(기타).

## 화면 구조

```
KPI 4장 (누르면 목록이 좁아짐)   신규(미처리) · 연락중·처리중 · 이번 주 완료 · 오늘 다음 액션
유형 탭                          전체 · 무료체험신청 · 매니저지원 · 도입상담신청   (빨간 숫자 = 신규)
필터 바                          상태 · 담당자(미배정 포함) · 정렬 · 검색(이름·연락처·지역·접수번호)
목록 + 상세 패널                 PC: 표 옆 고정 패널 / MO: 카드 → 아래에서 올라오는 시트
```

## 처리 상태

| 상태 | 뜻 | 자동으로 바뀌는 때 |
|---|---|---|
| `신규` | 아직 아무도 손대지 않음. 메뉴의 빨간 숫자가 이것을 셈 | 접수 직후 |
| `연락중` | 담당자가 배정됨·연락 시도 중 | 신규 건에 담당자를 배정하면 |
| `처리중` | 체험 진행·면접·상담 등 실무 진행 | 점주 가입이 승인되면 |
| `완료` | 끝남 | 트라이얼 지점이 「정식 전환」되면 |
| `보류` | 잠시 멈춤 | — |

상태·담당자가 바뀌면 상담 이력에 **자동 기록**(회색 한 줄)이 남습니다. 사람이 쓴 메모는 흰 카드입니다.

## 다음 액션

날짜 + 한 줄. 날짜가 오늘이거나 지났는데 완료가 아니면 **빨간 글씨**, KPI 「오늘 다음 액션」에 잡힙니다.
가입 승인 시 체험 마지막 날이 다음 액션으로 자동 지정됩니다(「무료체험 종료 · 정식 전환 상담」).

## 무료 트라이얼과의 연결

점주 가입 → 리드 생성(신규) → 승인 → 리드 「처리중」+ 체험 기간 기록 → D+14 자동 종료 → 리드에 「체험 종료 · 전환 여부 확인」다음 액션 → 정식 전환 → 리드 「완료」.
자세한 트라이얼 운영은 [무료 트라이얼](./trial) 을 보세요.

## 엑셀 · 삭제

- **엑셀 다운로드** — 지금 화면에 걸러진 목록을 그대로 내립니다(유형별 상세 항목 포함).
- **삭제** — 관리자만. 개인정보 파기용입니다. 상세 패널 바닥 왼쪽의 「삭제」. 되돌릴 수 없습니다.

## 자주 묻는 것

- **홈페이지에서 신청했다는데 목록에 없다** → `환경설정 › API 관리 › 최근 요청 기록` 에서 그 시각의 호출이 있는지, 거절됐다면 사유(검증 실패·인증 실패·호출 제한)를 봅니다. 호출 자체가 없으면 홈페이지 쪽 환경변수(`CRM_INTAKE_URL` · `CRM_API_KEY`)를 확인합니다.
- **같은 사람이 두 번 신청했다** → 10분 안의 같은 번호·같은 유형은 새로 만들지 않고 기존 건으로 돌려줍니다. 그 뒤라면 두 건이 생기며, 하나를 보류·삭제하면 됩니다.
- **본사 담당자도 쓸 수 있나** → 예. 목록·상태·담당자·메모 전부. 삭제와 API 키 관리만 관리자입니다.

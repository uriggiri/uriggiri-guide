# 재고 관리

`통합관리 → 재고 관리`

## 위쪽 숫자

폐기 대상 · D-14 이벤트 · 정상 · 전체 등록. 누르면 해당 항목이 있는 지점만 남습니다.

## 필터

| 칩 | 뜻 |
|---|---|
| 전체 지점 | 기본값 |
| 등록 있음 | 재고를 한 건이라도 올린 지점 |
| **등록 없음** | 한 건도 올리지 않은 지점 — **이쪽이 대개 확인이 필요한 지점입니다** |

「재고 있는」이 아니라 「등록 있는」입니다. 재고가 0인 것과 등록을 안 한 것은 다릅니다.

## 지점 상세

행을 누르면 그 지점의 품목이 열립니다. 임박순이 기본이고 이름순으로 바꿀 수 있습니다.

## 좁은 화면

열이 많은 표라 카드로 접지 않고 **조밀 규격**으로 그립니다
([디자인 시스템](/banauto/design-system#조밀-규격-예외)).
상품명만 두 줄로 접힙니다 — 잘리면 무엇인지 알 수 없는 유일한 열이기 때문입니다.

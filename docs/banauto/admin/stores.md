# 매장 현황

`통합관리 → 매장 현황`

전 지점을 지역으로 묶어 보여줍니다. 다른 통합관리 화면들이 이 화면의 짜임을 따릅니다.

## 지점 분류

| 분류 | 색 |
|---|---|
| 가맹 | 회색 |
| 직영 | 파랑 |
| 키즈룸 | 보라 |
| 폐업 | 흐린 회색 — 목록에서 뒤로 물러납니다 |

## 지점 상세

행을 누르면 오른쪽에서 열립니다. 그 지점의 담당자·계약 기능·좌표·운영 설정을 확인합니다.

## 지점 추가·수정

관리자만 할 수 있습니다. 지점을 지울 때 연관 데이터가 있으면 **폐업 처리**로 넘어갑니다 —
근태·발주 같은 운영 기록을 함께 지우지 않기 위해서입니다.

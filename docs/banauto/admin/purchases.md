# 발주·정산 관리

`통합관리 → 발주·정산 관리`

지점이 올린 **발주요청**(물품을 보내 달라)과 **정산요청**(매니저가 쓴 비용을 돌려 달라)을 처리합니다.

## 총 · 완료 · 미완료

건수 하나만 보면 **12건이 다 끝난 지점과 12건이 다 남은 지점이 같아 보입니다.**
그래서 유형마다 셋으로 나눕니다.

```
발주요청  232      정산요청  43
완료 144 · 미완료 78 · 반려 10     완료 9 · 미완료 34
```

| | 뜻 |
|---|---|
| 완료 | 처리가 끝난 것 |
| 미완료 | 대기·승인·처리중 — **아직 손이 가야 하는 것** |
| 반려 | 되돌려보낸 것. 완료도 미완료도 아니라 있을 때만 표시 |

색이 상태를 말합니다 — **초록은 끝난 것, 주황은 남은 것**.

## 표 읽는 법

머리가 두 단입니다. 윗단이 요청 유형, 아랫단이 그 안의 총·완료·미완료입니다.
한 단에 여섯 칸을 늘어놓으면 두 묶음이라는 게 읽히지 않습니다.

머리를 누르면 정렬합니다. **「미완료 많은순」**이 실무에서 가장 자주 쓰는 정렬입니다.

## 요청 처리

지점 행을 누르면 요청 목록이 열리고, 요청을 누르면 항목별로 검토합니다.

- 항목마다 **승인 · 수정 · 반려**를 따로 정할 수 있습니다 (수량·단가를 고쳐서 승인)
- 승인하면 지점이 **수령 확인**을 합니다
- 진행 단계는 `작성 → 검토 → 수령 → 완료` 네 칸으로 보입니다

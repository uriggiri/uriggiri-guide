# 통합 대시보드

`통합관리 → 통합 대시보드`

아침에 첫 번째로 여는 화면입니다. **오늘** 기준으로 전 지점의 상태를 모읍니다.

## 위쪽 — 오늘의 숫자

출근·체크리스트·재고·요청을 지점 수 대비로 보여줍니다.
카드를 누르면 아래 목록이 그 조건으로 좁혀집니다.

## 지점 추이

날짜를 가로로 놓고 지점을 세로로 놓은 표입니다. **한 달을 한눈에 보는 자리**입니다.

- 일별 출퇴근 인원 · 체크리스트 완료율 등을 지점별로 늘어놓습니다
- 왼쪽 지점 열은 가로로 밀어도 **따라옵니다** — 어느 지점 줄인지 잃지 않게
- 값이 없는 날은 `—` 입니다

::: warning 「—」는 「0명」이 아니라 「기록이 없음」입니다
출근을 했는데 `—` 로 보인다면 기록이 남지 않은 것입니다.
[출퇴근 관리](/banauto/admin/attendance#기록이-없을-때-확인하는-순서)의 확인 순서를 따라가세요.
:::

## 자주 묻는 것

**Q. 어제까지는 있었는데 특정 날짜부터 뒤가 통째로 비어 있어요**
조회가 조용히 잘렸을 때 나타나는 모양입니다. 서비스 쪽 문제이니 개발팀에 알려 주세요.
(1000행 상한 문제는 2026-09-01 에 전수 수정했습니다)

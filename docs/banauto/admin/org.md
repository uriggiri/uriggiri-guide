# 조직관리

`통합관리 → 조직관리` · **관리자 전용**

## 다섯 개 탭

| 탭 | 하는 일 |
|---|---|
| 직원 | 계정 목록. 역할·담당지점 확인, 편집·비밀번호 초기화·비활성화 |
| 지점 | 지점 목록과 배정 인원 |
| 지점 검색 | 지점을 골라 그 지점의 인원을 확인 (왼쪽 목록 · 오른쪽 결과) |
| 승인 요청 | 가입 신청 승인/거절. 어느 지점으로 신청했는지 함께 보입니다 |
| 비활성화 | 멈춘 계정. 다시 활성화하거나 지웁니다 |

## 계정을 멈추는 것과 지우는 것

::: warning 둘은 다릅니다
- **비활성화** — 잠시 멈춥니다. 로그인만 막히고 목록에는 「비활성화」 탭에 남습니다. 되돌릴 수 있습니다
- **계정 지우기** — 되돌릴 수 없습니다. 비활성화된 계정에서만 할 수 있습니다
:::

### 계정 지우기를 하면

| | |
|---|---|
| 로그인 | 막힙니다 (인증 계정 삭제) |
| 이메일·연락처 | 지워집니다 |
| **이름·역할** | **남습니다** |
| 지점 배정 | 해제됩니다 |
| 목록 | 어느 탭에도 나오지 않습니다 |
| 그 사람이 남긴 발주·게시글·근태 | **그대로 남습니다** |

기록에는 「삭제된 계정」(회색)으로 보이고, **마우스를 올리면 이름과 삭제일**이 나옵니다.

::: danger 데이터베이스에서 직접 지우지 마세요
2026-09-01 에 계정을 DB 에서 직접 지운 적이 있습니다. 그 결과
발주 12건·게시글 12건·출퇴근 30건·재고 79건의 **작성자가 영구히 사라졌습니다.**
무엇을 했는지는 남았는데 누가 했는지는 되찾을 수 없습니다.
반드시 이 화면의 「계정 지우기」를 쓰세요.
:::

막아 둔 것 — **자기 계정**과 **조직의 마지막 관리자**는 지울 수 없습니다.

## 가입 승인

신청은 「승인 요청」 탭에 쌓입니다. 승인 전에는 로그인할 수 없고,
거절하면 계정이 완전히 삭제되어 **같은 이메일로 다시 신청**할 수 있습니다.

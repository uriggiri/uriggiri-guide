# 환경설정

`통합관리 → 환경설정` · **관리자 전용**

지점마다 다른 운영 규칙을 정하는 곳입니다. 여기서 정한 값이 지점 화면의 동작을 바꿉니다.

## 출퇴근 설정

지점별 **인정 시간**(시작 · 종료)을 정합니다.

::: warning 이 값이 영업일 경계입니다
`18:00 ~ 10:00` 처럼 자정을 넘기면, 그 매장의 하루는 **오전 10시에 끊깁니다.**
중복 출근 방지도 이 단위로 걸립니다 — 자세한 것은
[출퇴근 관리](/banauto/admin/attendance#영업일이라는-단위)를 보세요.
:::

## 리포트 설정

지점별로 어떤 항목을 리포트에 넣을지 켜고 끕니다.
지점이 128개라 표가 넓어지는데, **왼쪽 지점 열은 가로로 밀어도 따라옵니다.**

## 계약 기능 관리

지점마다 **열어 둔 기능**을 정합니다. 여기서 끄면 그 지점에서는 메뉴가 사라지고,
화면에서 감추는 것으로 끝나지 않고 **서버에서도 막힙니다**.

## 카테고리 · 수시확인 항목

발주 분류, 체크리스트의 수시확인 항목을 관리합니다. 지우기는 빨간 상자입니다.

## 고객센터 이벤트 수집

어떤 사건을 고객센터로 모을지 지점별로 정합니다. 지점명 검색이 됩니다.

## 알림톡 설정

알림톡·문자를 보내는 솔라피 계정을 **배포 없이** 운영합니다 — API 키/비밀키 · 발신번호 · 카카오 채널(pfId) ·
템플릿 3개 · 무엇을 보낼지 켬/끔 · 가입 문자 인증 켬/끔.

- **비밀키는 저장 뒤 화면에 다시 나오지 않습니다.** 「설정됨」만 보이고, 바꾸려면 새로 칩니다. 빈 칸으로 저장하면 「바꾸지 않음」입니다.
- 설정이 비어 있으면 서버 환경변수(`SOLAPI_*`)로 폴백합니다. 어느 쪽 값을 쓰는지 상단 상태줄에 나옵니다.
- **테스트 발송**: 저장된 설정으로 내 번호에 실제 한 통. 「저장됨」과 「나간다」는 다른 말입니다 — 발신번호 미등록, 템플릿 검수 같은 것은 보내 봐야 압니다.
- 「문자 인증 사용」은 비상 스위치입니다. 끄면 가입 때 번호 형식만 확인합니다.

| 템플릿 | 언제 | 변수 |
|---|---|---|
| 회원가입 신청 완료 | 가입 버튼 직후 | `#{이름}` |
| 가입 승인 | 승인 직후, 트라이얼 지점만 | `#{이름}` `#{시작일자}` `#{종료일자}` |
| 무료체험 종료 D-3 | 매일 10시 크론 | 없음 |

템플릿 문구를 바꾸면 카카오 재검수를 거치고 ID 가 바뀔 수 있습니다 — 그때 여기서 교체합니다.

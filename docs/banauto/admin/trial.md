# 무료 트라이얼 (14일)

반오토 도입을 검토하는 신규 점주에게 **결제 없이 14일** 동안 베이직 3종을 열어 줍니다.
역할·권한은 그대로이고, **지점에 「트라이얼 상태」가 하나 얹힐 뿐**입니다.

| 상태 | 뜻 |
|---|---|
| `체험 대기` | 트라이얼 지점으로 등록됐지만 아직 승인된 계정이 없음 |
| `체험 D-n` | 체험 중. 마지막 날까지 n일 |
| `체험 종료` | 기간이 끝나 소속 계정 로그인이 막힘 |
| `정식 전환` | 계약 체결. 이후는 일반 지점과 같음 |

## 흐름 — 누가 무엇을 언제

```
① 신청 접수 (bahnauto.kr/trial, 영업)
② 관리자: 조직관리 > 지점 추가 → 「무료 트라이얼 지점」 켬          → 체험 대기
③ 점주: 회원가입 (휴대폰 문자 인증 필수) → 가입 신청 알림톡
④ 관리자: 조직관리 > 승인 요청 > 승인                              → D+0 · 체험 중
     · 베이직 3종 기능이 자동으로 열림 · 승인 알림톡(시작일·종료일)
⑤ D-3 10:00: 종료 안내 알림톡 (자동)
⑥ D+14 00:00: 로그인 차단 (자동)                                  → 체험 종료
     · 점주 화면에 「담당자에게 연결하기」 팝업
⑦ 관리자: 지점 목록 > 🎁 > 「정식 전환」 (또는 「다시 열기 +N일」)  → 정식 전환
```

::: warning 종료일은 「마지막으로 쓸 수 있는 날」입니다
승인일이 9/8 이면 9/8 ~ 9/21 열네 날을 쓰고 **9/22 0시**에 닫힙니다. 알림톡의 「체험 종료일」은 9/21 입니다.
차단 시각(9/22)을 종료일이라고 말하면 점주는 22일까지 되는 줄 압니다.
:::

## 열리는 기능 (베이직 3종)

| 묶음 | 기능 키 |
|---|---|
| 운영 대시보드 | 오늘의 리포트 · 출퇴근관리 · 체크리스트 · 재고관리 · 게시판 |
| 매니저 지원센터 | 매뉴얼 (+ 채널톡은 전 역할 공통) |
| 인허가·서류관리 | 인허가·서류 관리 |

**스탬프 이벤트는 열리지 않습니다.** 등록·승인 때 계약 기능 관리가 자동으로 이 목록으로 맞춰지고,
정식 전환 뒤에는 계약대로 관리자가 조정합니다.

## 관리자가 하는 일

### 지점 등록
조직관리 > 지점 추가 폼 맨 아래 **「무료 트라이얼 지점」** 토글. 이미 있는 지점은 목록의 🎁 버튼에서 「트라이얼로 등록」.

### 승인
승인 요청 탭에서 트라이얼 지점 신청에는 **「승인 시 무료체험 14일 시작」** 이 붙습니다. 승인 확인창에도 같은 말이 나옵니다.
승인 순간이 D+0 이고, 같은 지점에 두 번째 계정(매니저)이 나중에 승인돼도 시작일은 바뀌지 않습니다.

::: danger 본사 담당자 신청은 한 번 더 봅니다
본사 담당자는 **전 지점 자료를 봅니다.** 외부인이 이 역할로 신청할 수 있어, 승인 요청 목록과 확인창에
「전 지점 열람」 경고가 붙습니다. 본사 직원이 맞는지 확인하고 승인하세요.
:::

### 종료 뒤
지점 목록 🎁 > 다이얼로그에서:
- **정식 전환** — 차단이 풀리고 계속 이용. 계약 기능 관리에서 범위를 계약대로 맞춰 주세요.
- **다시 열기 (+3/7/14/30일)** — 영업 협의 중 며칠 더. 종료일이 늘고 D-3 안내가 다시 나갑니다.
- **이력** — 등록·시작·안내·종료·전환이 누가 언제 했는지 남습니다. 전환율·이탈율은 여기서 셉니다.

## 점주가 보는 것

- 가입 폼: 점주는 휴대폰 필수 → 「인증번호」 → 6자리 입력 → 인증됨. 번호를 고치면 다시 인증.
- 알림톡 3통: 가입 신청 완료 · 승인(시작일·종료일) · 종료 D-3.
- 종료 뒤 로그인: 「무료체험 기간이 종료되어, 접속이 불가합니다」 + **담당자에게 연결하기**(채널톡). 자료는 보관됩니다.

## 자동으로 도는 것

| 시각(KST) | 작업 | 경로 |
|---|---|---|
| 매일 00:05 | 기간 지난 지점을 `체험 종료`로 | `/api/v1/trial/expire` |
| 매일 10:00 | D-3 안내 알림톡 | `/api/v1/trial/notify-d3` |

차단 자체는 크론이 아니라 **로그인 API 와 지점 목록 API 가 직접** 판단합니다 — 크론이 늦거나 죽어도 자정부터 닫히고,
저장된 토큰으로 자동 로그인하는 앱도 지점 목록에서 걸립니다. D-3 안내는 하루 놓쳐도 마지막 날 전이면 보냅니다.

## 문제가 생기면

| 증상 | 볼 곳 |
|---|---|
| 알림톡이 안 왔다 | 환경설정 > 알림톡 설정 > 테스트 발송 → `message_logs`(status·error) → 솔라피 콘솔 |
| 승인했는데 체험이 안 시작됐다 | 지점이 「체험 대기」였는지(일반 지점이면 시작되지 않음) → 🎁 이력 |
| 점주가 못 들어온다 | 지점 상태가 종료인지 → 다시 열기 또는 정식 전환 |
| 인증 문자가 안 온다 | 같은 번호 60초 1회·1시간 5회 제한 · 알림톡 설정의 「문자 인증 사용」 |

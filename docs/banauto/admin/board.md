# 게시판

`통합관리 → 게시판`

## 두 갈래

| | 무엇 |
|---|---|
| **전체** | 지점들이 올린 글을 날짜별로 모아 봅니다 |
| **공지사항** | 본사가 지점에 내려보낸 글. 여러 지점에 동시 발행되면 한 줄로 묶입니다 |

예전에는 공지가 전체 목록에 섞여 있었습니다. 성격이 다른 글이라 목록을 나눴습니다.

## 목록

- **날짜로 묶여** 내려옵니다. 정렬은 최신순 하나입니다 — 다른 열로 줄을 세우면 묶음이 뜻을 잃습니다
- 한 번에 **50건**씩, 「더 보기」로 이어 받습니다
- 지점·분류·긴급 여부로 좁힙니다. 분류 필터의 **「미지정」**은 분류를 고르지 않고 올린 글입니다
- 지점 선택은 검색이 됩니다 (지점이 128개입니다)

## 글 미리보기

행을 누르면 팝업에서 바로 읽습니다. 사진은 눌러서 크게 볼 수 있습니다.
확인 처리·댓글은 팝업에서 하지 않습니다 — 하단 **「지점 게시판 열기」**로 넘어가서 합니다.

::: tip 왜 팝업인가
전 지점 글을 훑는 화면입니다. 행마다 지점 게시판으로 넘어갔다 돌아오면
다음 글을 보기까지 왕복이 반복됩니다.
:::

## 공지 발행

「+ 작성하기」에서 대상 지점과 확인 대상 역할을 정해 발행합니다.
지점별로 복제 발행되며, 목록에서는 `N개 지점`으로 묶여 보입니다.

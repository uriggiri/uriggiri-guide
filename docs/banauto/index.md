# 반오토

무인매장 위탁관리 서비스입니다. 본사가 여러 지점의 근태·재고·발주·업무를 한 화면에서 관리하고,
각 지점 매니저는 자기 매장의 일을 처리합니다.

## 두 개의 얼굴

같은 서비스지만 보는 사람에 따라 화면이 갈립니다. 좌측 상단에서 전환합니다.

| | 쓰는 사람 | 하는 일 |
|---|---|---|
| **통합관리** | 본사 관리자 · 본사 담당자 | 전 지점을 가로로 훑고, 요청을 처리하고, 설정을 정한다 |
| **지점관리** | 점주 · 매장 매니저 | 자기 매장의 출퇴근·재고·체크리스트를 기록한다 |

이 문서는 **통합관리**를 다룹니다. 지점관리 쪽은 순차적으로 추가합니다.

## 역할 네 갈래

| 역할 | 색 | 볼 수 있는 범위 |
|---|---|---|
| 관리자 (HQ_ADMIN) | 빨강 | 전 지점 + 조직·환경 설정 |
| 본사 담당자 (HQ_STAFF) | 파랑 | 전 지점 조회·처리 |
| 점주 (STORE_OWNER) | 주황 | 소속 지점 |
| 매장 매니저 (BRANCH_MANAGER) | 초록 | 소속 지점 (점주 전용 기능 제외) |

색은 화면 어디서나 같습니다 — 이름 앞 동그란 이니셜도 같은 색을 씁니다.
